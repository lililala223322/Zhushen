# 成长计算网页

本目录是成长计算系统的第一部分：输入角色培养方案，计算常态属性和战斗属性，展示每个属性的公式拆解，按技能门槛反推成长路线修正方案，并评估血脉/神子组合的构筑上限。

## 启动

在项目根目录运行：

```powershell
python -m http.server 8765 --directory web
```

然后访问：

```text
http://127.0.0.1:8765/
```

也可以直接打开 `web/index.html`，但推荐使用本地静态服务。

## 已实现

- 在角色基础中选择性别，并配置多条血脉和血脉百分比。
- 可将当前角色的性别、血脉和特性保存为本地角色模板。
- 可启用当前状态作为规划起点，填写当前等级、当前职业和脱装后六维面板值。
- 当前状态会剥离乘区、特性值和当前职业值，反推出已有成长值并作为后续规划基础。
- 血脉百分比合计小于 100% 时，自动用平民血脉补足。
- 按血脉百分比计算角色潜力上限，并允许手动填写实际角色潜力。
- 在成长路线中配置目标等级和多段职业成长区间；区间会按起始等级自动排序，并提示重叠、越界或低于当前等级后的可规划范围。
- 按血脉筛选可用神技；普通神技要求对应血脉大于 70%，圣子神技不受血脉限制。
- 按聚合项选择特性，神技互斥，凡人特性只显示血脉最高的前两个种族。
- 支持手动收起或展开特性聚合项，并在神子特性右侧展示人物潜力影响。
- 展示特性部位、效果和寿命字段，并校验神技数量、部位冲突、神子特性数量、凡人特性数量和凡人种族数量。
- 输入六维装备值。
- 选择最终职业并使用职业值。
- 计算常态属性和战斗属性。
- 展示人物潜力、潜力分级、最终潜力、成长值、神技加值、特性值、装备值、职业值、乘区和公式。
- 数值输入在失焦或确认后应用，避免逐键输入时重复触发重计算。
- 配置技能门槛目标、检查组、属性套装、武器/护甲类型，并勾选核心属性。
- 根据职业装备适配性，自动匹配每个门槛可用的套装与学习职业。
- 当前路线不达标时，使用全职业潜力表搜索核心属性损失合计最低的成长替换方案，并支持多目标同时达标。
- 技能门槛规划作为左侧“规划”独立视图进入，不插入属性计算主流程下方。
- 新增左侧“上限”视图，用于构筑上限评估。
- 上限评估会直接复用“属性”页中用户已指定的血脉、神技和特性。
- 上限评估可调用本地保存的角色模板做批量评估。
- 系统按血脉成长上限生成随机六维样本，并根据目标权重、负重和技能门槛抬高相关属性采样下界。
- 对每个构筑样本自动搜索最优成长职业有效等级分配，优先展示战斗六维和对应原始潜力，评分、参考成长路线和硬约束缺口默认折叠。
- 负重以最终战斗状态校验，技能门槛可复用“规划”页中的目标和属性套装。
- 随机样本数和随机种子由系统按评估轮次与上次耗时自动调整，不暴露为用户输入。
- 上限页按角色身份保留最佳方案；同一角色重复评估时，只有更优结果会替换旧结果。
- 内置法拉样例。
- 支持本地保存和载入。

## 文件结构

```text
index.html    页面入口
styles.css    页面样式
data.js       结构化规则数据
calc.js       纯计算和校验逻辑
app.js        页面交互和状态管理
```

## 当前限制

- 第一版是无依赖静态网页，尚未拆成前后端服务。
- 技能门槛规划按常态属性计算；未填写检查组的目标会分别匹配学习状态，填写相同检查组的目标会要求同一套装和同一职业同时满足。
- 构筑上限评估当前在主线程同步执行；样本数会根据耗时自动调整，后续大规模搜索应迁移到 Web Worker 或后端任务。
- 构筑上限评估的成长路线搜索以“职业有效等级分配”为单位，不展示逐级替换路径。
- `data.js` 已录入 `培养.md` 中成长计算涉及的六维固定值、百分比乘区、潜力成长、职业成长和职业值；攻击力、生命、命中、暴击等战斗字段留给后续战斗模块。
- 特性效果和寿命文本目前优先补了法拉相关常用项，其余项会显示结构化六维摘要和“未录入”寿命占位，后续可继续补齐完整文本元数据。
